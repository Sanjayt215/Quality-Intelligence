# PHASE 14 — Data Source & Provenance Matrix

## 1. Overview & Classification Schema

To prevent misleading cross-feature data pollution, Quality Intelligence establishes a strict data source taxonomy. Every UI view and API response exposes explicit data scope badges.

### Taxonomy Tiers:

1. **`REAL_GIT_COMMIT`**: Live extraction from a cloned or local Git repository for a specific commit SHA. Includes exact diff statistics (lines added, deleted, files modified, entropy, author experience).
2. **`REAL_GIT_BRANCH`**: Batch sequential analysis across an active branch of a connected Git repository.
3. **`MODEL_PREDICTION`**: Probability output generated by the frozen Random Forest (200 trees) evaluated against the 26 derived features of the active commit.
4. **`APACHEJIT_HISTORICAL_BENCHMARK`**: Reference distributions, LOPO transfer benchmarks, and covariate drift baseline calculated strictly from the quarantined ApacheJIT holdout / training set.
5. **`SYNTHETIC_DEMO`**: Archetypal demonstration scenarios (`critical_silent_risk`, `benign_refactoring`, `high_churn_low_risk`) used solely for offline workflow demonstrations.
6. **`INSUFFICIENT_DATA`**: Honest placeholder state displayed when repository-level statistics require multi-commit histories (e.g. fewer than 2 commits analyzed for budget optimization).
7. **`OUTCOME_PENDING`**: Feedback entries whose 90-day observation window has not elapsed.

## 3. Disclaimers & Integrity Invariants

- **Cryptographic Integrity vs. Ground Truth**: A valid SHA-256 execution manifest proves that the reported inputs, model parameters, and outputs match the recorded execution payload without tampering. It does **not** prove that the underlying prediction is an infallible ground truth.
- **Unfamiliar Repository Generalization**: Defect-risk scores on unfamiliar repositories (e.g. `commons-lang`) reflect feature similarity to the Apache training corpus, rather than calibrated silent-regression probabilities. LOPO transfer evaluations demonstrate that cross-project ranking performance varies across repository architectures.
